# Dennis-F-Brodfsky.github.io

Dennis-F-Brodfsky 的个人博客，使用 GitHub Pages 与 Jekyll 构建。

## 本地开发

安装依赖：

```bash
bundle install
```

启动本地服务：

```bash
bundle exec jekyll serve
```

包含草稿启动：

```bash
bundle exec jekyll serve --drafts
```

生产构建验证：

```bash
bundle exec jekyll build
```
